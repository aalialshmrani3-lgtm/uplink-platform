# CR-01 — Submission Types, Evidence Vault, Innovation Passport, TRL Evidence Engine

## الهدف

ينفذ هذا الطلب التغييري الطبقة الأولى فقط من إعادة بناء NAQLA: فهم **ما الذي يملكه المستخدم** قبل تقييمه، وربط التقييم بنوع المدخل والأدلة المتاحة بدلاً من فرض درجة TRL أو مسار واحد على جميع الأفكار.

> CR-01 لا ينفذ CR-02 إلى CR-05. لا يتضمن مطابقة حية، أو تنبيهات فرص حية، أو معاملات، أو تحويل أموال، أو تكامل SAIP أو MISA أو المركز السعودي للأعمال.

## حدود CR-01

| المجال | داخل النطاق | خارج النطاق |
|---|---|---|
| نوع المدخل | تصنيف أنواع المدخل وتحديد المسار المناسب | بناء محرك Demand Exchange كامل |
| TRL | المعلن، والمقدر بحسب الأدلة، والموثق كحالة سير عمل | اعتماد خبير أو تكامل جهة خارجية |
| الأدلة | وصف الأدلة، النوع، المصدر، الحالة، وعلاقة الدليل بالـTRL | مراجعة قانونية أو علمية ملزمة |
| الملكية الفكرية | رقم طلب يصرح به المستخدم وحالة غير متحقق | تقديم أو تحقق رسمي لدى SAIP |
| Passport | مؤشرات الجاهزية وخطة الأدلة التالية | قرار استثماري أو ضمان جودة أو ترشيح رسمي |
| المسارات | إشعار المسار المقترح نحو NAQLA 2 أو 3 | ترحيل الصفقة أو التنفيذ التجاري |

## أنواع المدخل المعتمدة

| نوع المدخل | يطبق TRL | نتيجة CR-01 المتوقعة |
|---|---:|---|
| فكرة أولية | لا | Innovation Passport بلا TRL وخطة تطوير أولية |
| ابتكار أو تقنية | نعم | TRL Evidence Engine وPassport |
| ناتج بحثي | نعم | TRL Evidence Engine وPassport |
| حل تجاري | لا | Commercial/Market Passport بلا TRL |
| منتج رقمي أو AI | بحسب الجوهر التقني | TRL أو Product Maturity مع توضيح الملاءمة |
| شركة ناشئة قائمة | بحسب جوهر المنتج | Product/Commercial metrics وTRL عند الانطباق |
| أصل ملكية فكرية | بحسب التقنية | Passport مع رقم يصرح به المستخدم |
| تحدٍ أو جهة أو فعالية | لا | مسار NAQLA 2 مقترح فقط |
| أصل تجاري جاهز | بحسب الأصل | مسار NAQLA 3 مقترح فقط |

## معايير القبول القابلة للاختبار

1. لا يظهر حقل TRL ولا أي نتيجة TRL لفئة لا تنطبق عليها التقنية.
2. تظهر للمشروع التقني ثلاثة حقول منفصلة: **TRL المعلن**، و**TRL المقدر بحسب الأدلة**، و**TRL الموثق** مع حالة واضحة.
3. لا يعرض النظام عبارة «موثق من SAIP» أو «تم التحقق من الملكية الفكرية»؛ رقم الطلب المستخدم يوسم بأنه تصريح مستخدم.
4. يمكن لصاحب المشروع إضافة بيانات دليل منظمة وربطها بمستوى TRL وحالة مراجعة، دون أن تعد هذه العملية اعتماداً خبيراً.
5. يوضح Passport الأدلة الموجودة، والفجوة التالية، والإجراء المقترح للوصول إلى المستوى التالي.
6. مشروع AI Energy Optimizer التجريبي يوضح: TRL معلن 5، ودليل يدعم TRL 4، وثقة دليل تجريبية، ووسم Demo Data.
7. تفرض الإجراءات الخلفية ملكية المستخدم قبل القراءة أو التحديث، ولا تعيد أي بيانات سرية أو بيانات إنتاجية إلى واجهة العرض التجريبية.

## شرط التوقف

بعد إكمال CR-01 واختباره، يتوقف التنفيذ قبل CR-02 إلى CR-05 حتى اعتماد المستخدم الصريح للنتيجة.
